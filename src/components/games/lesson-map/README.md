# Lesson journeys

`LessonJourneyMap` is the shared renderer for every subject and grade. It owns responsive snake positioning, measured SVG paths, locked feedback, navigation through `LessonJourneyNode`, and optional scroll to the current lesson. `LessonStars` and `ClassProgress` are shared presentation components.

- Math: `LessonMap` preserves its existing API and supplies `theme="ocean"`.
- English (Vũ trụ tiếng Anh): the route uses `AccountLessonMap` with `subject="tieng-anh"` and `theme="space"`; the shared node selects `PlanetArtwork`. Signed-in users load account progress; guest demo items come from `englishData.ts`.
- Vietnamese (Vùng đất tiếng Việt): the route uses `AccountLessonMap` with `subject="tieng-viet"` and `theme="adventure"`. Signed-in users load their progress from the lesson-map API; only guests see the demo from `vietnameseData.ts`. The shared node selects `AdventureLocationArtwork` using each definition's `nodeType` and `isCheckpoint`, with `mapTitle` as the visible place name; artwork contains no text. Ten literacy scenes use a bright sky/grass/water palette, gently staggered positions, and a single dashed dirt path that joins scene edges. The guest demo has 1/10 completed, lesson 2 current and lesson 3 available. Bài 1–10 currently use ComingSoon destinations and are locked in account progress until published in `progress-config.ts`. Current number badges remain blue across all three themes.
- Another grade: supply new definitions and grade/subject labels to the same renderer.
- Math landmarks: `mathIslandLandmarks.ts` defines 50 ordered visual identities in five categories. `LessonJourneyMap` passes the one-based item order, so every grade starts at crab and orders above 50 cycle. `IslandArtwork` places the reusable `IslandLandmark` inside its SVG, opposite the palm. Local SVG coordinates scale with the existing desktop/mobile artwork; landmark status filters do not alter progression or badge colors. Failed images disappear without affecting the node or click target.
- All 50 original SVG assets are in `public/game/math/island-icons/` (about 18 KB total); no assets are missing. SVG is used instead of WebP to match the existing vector islands. `node scripts/generate-math-landmarks.mjs` regenerates both assets and config; edit the generator when changing persistent defaults. Config supports position, scale, rotation and offsets, plus a 12% checkpoint size boost.
- Another visual theme: extend `JourneyTheme`, theme CSS, decorations and artwork selection. Keep layout, node interactions and progress merging shared.

Definitions contain stable `lessonId`, display content and the existing destination route. `buildLessonMapData(definitions, progress)` merges separately loaded progress; the first unlocked incomplete item becomes current, other unlocked items remain available. Completed items always remain replayable. English uses existing `tieng-anh-1-bai-*` IDs to match lesson tracking.

The English guest demo has 2 completed units and Unit 3 current. Account progress follows published lessons in `progress-config.ts`. No database migration is needed here. Units without game content use the existing ComingSoon presentation through the bounded `bai-3`–`bai-16` fallback route. English and Vietnamese hide the overview and tagline, matching main.

Run `node scripts/test-lesson-journey.cjs`, `npm run typecheck`, and scoped Next lint. Browser verification should cover 1920, 1440, 1280, 768, 390 and 375px, including resize, keyboard activation, locked feedback and the ocean route.
